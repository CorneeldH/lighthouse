## Lighthouse: shell

- Every edited `.sh` or `.bash` file is shellchecked; a finding blocks. `shell-lint-check: COULD NOT CHECK` means nothing was checked, not that the file is clean. <!--level:shell-lint-check-->
- Before writing shell that guards something (a hook, a gate, its tests), read the skill `lighthouse-shell-standard`. <!--level:skill:shell-standard-->
