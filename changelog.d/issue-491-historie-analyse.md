`lighthouse history` reads the Claude Code transcripts of a repo and prints one JSON report: where pushes go, how work is tracked, memory, shell, hooks and worktrees, each with a meaning and a proposal, plus a recommended start level (`--sources`, `--since`, `--projects-dir`). It reads only. The agent install guide gets a History step that asks for consent per harness and uses the report to steer the level and the first choices (#491).
