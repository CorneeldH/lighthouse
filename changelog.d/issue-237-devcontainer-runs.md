Controller runs in the devcontainer no longer strand silently. `Kill` and `Stop` find the session's `claude` in every devcontainer, so a new start in an existing workspace no longer fails with a 500. The tick reads a Software run's transcript from the container and sees an unknown command within one tick. A start moves a plan path from another checkout into the run's own worktree. The lighthouse project settings enable the superpowers plugin.
