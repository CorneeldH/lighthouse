# lighthouse web UI

The single-page app that `lighthouse serve` serves: Vite, React, TypeScript, Tailwind and
shadcn. The Go binary embeds the build output.

Node version: see [.nvmrc](.nvmrc).

## Install

```bash
npm ci
```

Always `npm ci`, never `npm install` with `--legacy-peer-deps` or `--force`.

## Develop

```bash
npm run dev
```

The dev server proxies `/api` to `127.0.0.1:8127`, so `lighthouse serve` must be running.

## Build

```bash
npm run build
```

The build writes to `../internal/web/dist`, which the Go binary embeds. Reinstall the binary
afterwards (`go install ./cmd/lighthouse` from the repository root) to serve the new build.
The build output is never committed.

## Checks

```bash
npm test           # vitest, component tests in jsdom
npm run lint       # eslint
npm run typecheck  # tsc -b, no emit
```

## API client

`src/api/` is generated by orval from [openapi.json](openapi.json). Never edit it by hand.

When the API changes, run from the repository root:

```bash
go test ./internal/server -run TestOpenAPISnapshot -update
cd web && npm run gen
```

The first command rewrites `web/openapi.json` from the API description the server serves. The
second regenerates `src/api/lighthouse.ts` from it. Commit both.
