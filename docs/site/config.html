This map reads its data with fetch, which a browser blocks for a page opened straight from disk. From the root of the repository, run python3 -m http.server --directory docs/site and open http://localhost:8000/config.html.

Wait, but why?

Two files. lighthouse.toml sits in the root of your repository. It holds the settings of that project. host.toml sits in ~/.config/lighthouse/ and holds the settings of one machine. lighthouse init writes lighthouse.toml, and on a machine with Tailscale it also offers to write host.toml. You edit both by hand after that.

Three levels. Not every key needs your attention. A key marked "Set this" has a default that rarely fits, or one that lighthouse init proposes, so check it. A key marked "Optional" works without a value and only adds a feature, such as the project board. A key marked "Advanced" has a default that most projects leave alone. Click a key in a file to see what it does and what reads it. Controller settings come later.

    • Set this: you fill it in
    • Optional: adds a feature
    • Advanced: most projects leave it alone
