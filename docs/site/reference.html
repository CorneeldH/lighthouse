    Skills

    A skill is a set of instructions the model follows. A workflow skill you or another skill start; a standard skill the model picks up by itself when its description matches the task.

    Agents

    An agent is a subagent with its own context, started for one narrow job.

    Hooks

    A hook is a script the harness runs on an event, such as a tool call, and it can check, format or block.

    GitHub

    lighthouse keeps the work on GitHub: issues carry the acceptance criteria, milestones group them, labels mark their state, and every change goes through a pull request. CI checks that pull request on GitHub. The pull request template and the GitHub Actions workflows that init installs are below.
