Install lighthouse

Lighthouse

latest release

Paste one block into a terminal. It checks the binary against SHA256SUMS before it puts it in ~/.local/bin, without sudo.

Linux x86-64 
cd "$(mktemp -d)" &&
curl -fsSLO https://github.com/CorneeldH/lighthouse/releases/latest/download/lighthouse_linux_amd64 &&
curl -fsSLO https://github.com/CorneeldH/lighthouse/releases/latest/download/SHA256SUMS &&
sha256sum --check --ignore-missing SHA256SUMS &&
chmod +x lighthouse_linux_amd64 &&
mkdir -p ~/.local/bin && mv lighthouse_linux_amd64 ~/.local/bin/lighthouse &&
~/.local/bin/lighthouse version

Not on your PATH yet? Add export PATH="$HOME/.local/bin:$PATH" to ~/.bashrc.

or download the file. Check it against SHA256SUMS and chmod +x it yourself.

Windows

The hooks need WSL: inside WSL, use the Linux x86-64 block. The Windows binary runs the CLI only. In PowerShell:

& {
  $ErrorActionPreference = "Stop"
  $ProgressPreference = "SilentlyContinue"
  $base = "https://github.com/CorneeldH/lighthouse/releases/latest/download"
  Invoke-WebRequest -UseBasicParsing "$base/lighthouse_windows_amd64.exe" -OutFile lighthouse.exe
  Invoke-WebRequest -UseBasicParsing "$base/SHA256SUMS" -OutFile SHA256SUMS
  $want = ((Select-String -Path SHA256SUMS -Pattern "lighthouse_windows_amd64.exe").Line -split "\s+")[0]
  $have = (Get-FileHash -Algorithm SHA256 lighthouse.exe).Hash.ToLower()
  if ($have -ne $want) { Remove-Item lighthouse.exe; throw "Checksum mismatch: lighthouse.exe removed" }
  .\lighthouse.exe version
}

or download the file. Check it against SHA256SUMS yourself.

Or install with Go, go install github.com/CorneeldH/lighthouse/cmd/lighthouse@latest, which puts the binary in ~/go/bin, or build it from a clone. A build from main or from a clone reports version dev, and lighthouse init writes that version into .lighthouse/manifest.toml, so install a tag for a repository you work in. The getting-started guide has the details.

Next: run lighthouse init in your repository, as the getting-started guide shows. Check the requirements first.
