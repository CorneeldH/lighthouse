# Het procesverslag van lighthouse zelf

Dit is laag 2: het procesverslag van lighthouse zelf, boven de tickets. Laag 1 is de tool
(`lighthouse report`), laag 3 de showcase; die valt buiten #128 (zie #89 en #93).

## Waar de verslagen staan

De gegenereerde verslagen staan in `day/`, `week/` en `month/` onder deze map, als `<label>.md`.
Ze komen uit `lighthouse report day` (of `week`, `month`). Het commando commit niets: een mens
commit het bestand.

## Verwijzingen

- [De roadmap](../strategie.md#roadmap): de roadmap zijn de milestones in rangorde op de forge.
  Er is bewust geen roadmapdocument (N2 in [meta](../areas/meta.md)). #102 is de systeemkaart (`docs/site/system.html`) en bevat
  volgens haar eigen acceptatiecriteria geen roadmap; AC3 van #128 wordt daarom gelezen als de
  roadmap van `strategie.md` (N2).
- [`lighthouse report`](../../report.md): de aanroep, de sleutels en het formaat van het verslag.
